## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Plugin Library** | Browse all installed FWS plugins with version and status info |
| **Config Profiles** | Save per-game fix configurations as named profiles |
| **Quick Toggle** | Enable or disable specific plugins without opening the main app |
| **Update Alerts** | Flags installed plugins with available updates |
